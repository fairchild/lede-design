Lede is a design system for React: components, blocks, page layouts and hero flows, installed from a shadcn registry.

The docs pages need JavaScript. These links work without it:

  • https://lede.cloudcompute.com/llms.txt, the docs index for agents and for reading without JavaScript
  • https://lede.cloudcompute.com/r/registry.json, the registry index: every item with its description and files
  • https://github.com/fairchild/lede-design, the source and the README
